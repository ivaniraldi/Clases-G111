Arreglos y objetos en JavaScript

Arreglos:

Un arreglo es una lista de datos ordenados en posiciones numéricas que empiezan desde cero y se guardan entre corchetes []. Sirve para reunir múltiples valores seguidos como productos de una compra o una serie de números donde lo importante es la secuencia que ocupan.

let frutas = [
  "Manzana",
  "Banana",
  "Naranja"
];

Objetos:

Un objeto guarda la información asociada en parejas de clave y valor y se guardan dentro de llaves {}. La clave funciona como una etiqueta (por ejemplo, nombre o edad) y el valor es el dato exacto guardado bajo esa etiqueta, permitiéndote describir un elemento completo de forma organizada.

let usuario = {
  nombre: "John",
  edad: 41,
  premium: true
};
